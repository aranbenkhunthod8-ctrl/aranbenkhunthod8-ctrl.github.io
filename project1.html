Raspberry Pi 4 Camera Module Python สิงหาคม 2026

รายละเอียดโครงการ

โปรเจกต์พัฒนาระบบสายพานตรวจสอบชิ้นงานอัตโนมัติ โดยใช้ Raspberry Pi 4 ร่วมกับ Camera Module และ Photoelectric Sensor เพื่อตรวจจับชิ้นงานที่วิ่งผ่านสายพาน หากระบบ Vision ตรวจพบชิ้นงานที่ไม่ได้มาตรฐาน จะสั่งการ Pneumatic Rejector ให้คัดแยกชิ้นงานออกทันที

ผลลัพธ์และการทำงาน

  • สามารถตรวจจับและคัดแยกชิ้นงานได้อย่างแม่นยำตามเงื่อนไขที่กำหนด
  • พัฒนาระบบ Web Dashboard แบบ Local Network สำหรับแสดงผลข้อมูลและสถานะของสายพานแบบเรียลไทม์
  • บูรณาการฮาร์ดแวร์เซนเซอร์และการควบคุมนิวเมติกส์เข้ากับซอฟต์แวร์ประมวลผลภาพได้อย่างสมบูรณ์
